Você é um engenheiro sênior de redes móveis, 5G-LENA, ns-3 e Open RAN. Sua tarefa é modificar uma simulação ns-3/5G-LENA existente para implementar, o mais próximo possível dentro das limitações do 5G-LENA, uma simulação de slicing 5G ponta a ponta para a proposta GreenRAN.

Contexto do estudo:
- A proposta GreenRAN possui duas aplicações principais:
  1. App1-Vigilância: vídeo de alta definição para vigilância do campus, associado ao slice eMBB. Cada câmera 4K deve gerar aproximadamente 25 Mbps e a rede deve buscar latência abaixo de 100 ms.
  2. App2-Monitoramento: sensores ambientais e de solo, associado ao slice mMTC. O foco é conectividade massiva, pacotes pequenos, tráfego intermitente, alta taxa de entrega, baixo consumo e baixo uso de recursos.
- O objetivo é simular dois slices ponta a ponta:
  Slice 0: VIDEO_EMBB
  Slice 1: SENSOR_MMTC
- A simulação deve ser principalmente uplink, pois câmeras e sensores enviam dados para servidor/data lake.

Objetivo geral:
Transformar a simulação atual, que usa slices eMBB/URLLC/MTC e tráfego predominantemente downlink, em uma simulação GreenRAN com dois slices de aplicação:
  VIDEO_EMBB: câmeras 5G/FWA enviando vídeo para servidor de IA/data lake.
  SENSOR_MMTC: sensores IoT enviando métricas ambientais/solo para data lake.

A simulação deve representar slicing ponta a ponta de forma funcional:
  UE/app -> RAN slice scheduler -> EPC/UPF abstrato do 5G-LENA -> remoteHost/data lake -> métricas por aplicação/slice.

Limitações importantes:
- Não implemente NSSF, AMF, SMF, UPF, PCF, NRF, SBI, NGAP ou PFCP reais. O 5G-LENA usa EPC/PGW como core abstrato.
- Não invente APIs do 5G-LENA. Antes de criar um override para UL scheduling, inspecione as classes base do 5G-LENA usadas pela versão local:
    NrMacSchedulerOfdmaRR
    NrMacSchedulerOfdma
    NrMacSchedulerNs3
    NrMacSchedulerUeInfo
- Se houver método virtual de alocação UL equivalente ao AssignDLRBG, implemente slicing UL nele.
- Se não houver método virtual direto, implemente a melhor aproximação possível usando os hooks disponíveis, documente claramente a limitação e mantenha slicing DL intacto.
- O código deve compilar no ns-3 local. Compile após cada alteração relevante.
